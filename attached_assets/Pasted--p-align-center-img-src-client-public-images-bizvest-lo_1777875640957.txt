## Overview
BizVest is a professional marketplace that connects business buyers, sellers, franchisors, and advisors on a single platform. It provides end-to-end tools for listing a business, performing due diligence, negotiating deals, and closing transactions — with AI-driven insights and Algorand blockchain tokenisation for fractional ownership.
All platform fees and base currency are in **GBP (£)**.
---
## Features
### Marketplace & Listings
- AI-assisted business listing wizard with financial parsing and document extraction
- Advanced search, filtering, and category-based browsing
- Featured listings, watchlists, and personalised recommendations
- Franchise opportunities directory with territory-based browsing
- Real estate listings alongside business listings
### Deal Management
- **Deal Rooms** — private M&A workspaces with interactive milestone trackers, document sharing, and messaging
- **Progressive Identity Disclosure** — seller identity remains confidential until NDA signing
- **Circumvention Monitoring** — background detection of off-platform communication
### AI & Automation
- AI-powered due diligence reports with risk scoring and consensus engine
- Universal document extraction (PDF, Excel, Word, images)
- AI chat support and buyer-seller matching
- Marketing collateral generation
- **Deal Copilot** — white-label AI workspace with document RAG (pgvector), Stripe seat billing, and custom subdomain support
- **AI Robo Advisor** — subscription-based portfolio management and investor risk profiling
- **Legal AI** — multi-tenant (firm-level) matter management with event-driven agent, partner escalation, and RAG over legal documents
### Blockchain & Tokenisation (Algorand)
- Fractional business ownership via Algorand Standard Assets (ASA)
- On-platform custody wallets with USDC deposit support
- Secondary marketplace with order book trading
- Dividend distribution with DRIP (Dividend Reinvestment Plan)
- Governance voting and payout management
- Token alerts (price, yield, volume) with configurable cooldowns
### Identity & Financial Verification
- **Veriff** KYC integration for identity verification
- Proof of Funds (POF) system with AI-powered document scanning and admin review
- Expiry notifications and dashboard warnings
### Payments & Monetization
- **Stripe** for card payments, subscriptions, and commissions
- Tiered commission structure with promotional overrides (e.g. First 100 Sellers flat-fee promo)
- Referral programme and featured listing upgrades
- Blog CMS for content marketing
### Communication
- Real-time messaging with WebSocket notifications
- Multi-language auto-translation in deal rooms
- PII filtering on messages
- Email notifications via Nodemailer (transactional + marketing outreach)
### Administration
- Role-based dashboards (buyer, seller, super admin, franchisor)
- Admin analytics with revenue dashboard
- Email outreach campaigns with merge tags, throttling, and live progress
- Legal AI firm management (create firms, assign members by role)

## Architecture

client/ React SPA (Vite)
src/
pages/ Page components (auth, browse, dashboard, deal-room, etc.)
components/ Shared UI components (admin panels, charts, forms)
hooks/ Custom React hooks (auth, toast, WebSocket)
lib/ Utilities (API client, query config)

server/ Express API server
routes.ts RESTful API routes
storage.ts Data access layer (IStorage interface + PostgreSQL impl)
db.ts Database connection (Drizzle + pg pool)
seed-admin.ts Schema sync & seed data on startup
services/ Background services & schedulers
dividend-scheduler.ts
token-alert-checker.ts
circumvention-monitor.ts
buyer-matching.ts
marketplace-emails.ts
...
deal-copilot/ Deal Copilot AI workspace (RAG, embeddings)
legal-ai/ Legal AI agent (events, handlers, memory, deliverables)

shared/
schema.ts Drizzle schema + Zod validators (single source of truth)

The application runs as a **single process** — Express serves the API and the Vite-built SPA from the same port. Background schedulers (dividends, token alerts, buyer matching, circumvention monitoring) run as in-process timers.

## Getting Started
### Prerequisites
- Node.js 20+
- PostgreSQL 15+
- Algorand node access (for blockchain features)
- Stripe account (for payments)
- Veriff account (for KYC)
- OpenAI API key (for AI features)
### Installation
```bash
# Install dependencies
npm install
# Push database schema
npm run db:push
# Start development server (frontend + backend)
npm run dev

The app will be available at http://localhost:5000.

Production Build
npm run build
npm start

Environment Variables
Variable	Description

SESSION_SECRET	Express session encryption key
STRIPE_SECRET_KEY	Stripe API secret key
STRIPE_PUBLISHABLE_KEY	Stripe publishable key
