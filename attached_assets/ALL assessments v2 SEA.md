# HumanMetrix Assessments v2 SEA
## Complete Question Bank and Scoring Logic (Southeast Asia / Tier 3 Localized Version)

This document contains all SEA-localized questions, answer options, and scoring logic for the four HumanMetrix assessments. The scoring matrices and mappings are identical to v1 - only the vocabulary has been adjusted for cultural relevance in emerging market regions.

# 1. FIT ASSESSMENT (Behavioural)

## Overview
- **Total Questions**: 15
- **Options per Question**: 4 (A, B, C, D)
- **Skills Measured**: 6 behavioural competencies

## Skill Definitions

| Code | Skill Name |
|------|------------|
| HA | High Agency |
| IC | Intellectual Curiosity |
| RA | Resilience |
| EE | Empathy & Ethics |
| GM | Growth Mindset |
| IA | Interpersonal Agility |

## Scoring Formula
- Each answer awards 4 points to each associated skill
- **Hybrid Scoring with Maximum Variance and Dynamic Floor:**
  - Dynamic floor based on minimum raw % (not always stuck at 50)
  - Ceiling at 100 for 100% raw performance, scaled down for lower performers
  - **Floor Formula:** `floor = 50 + (minRawPct / 100)^0.5 × 10` (gives 50-60 range)
  - **Ceiling Formula:** `ceiling = 50 + (maxRawPct / 100)^0.25 × 50` (gives up to 100)
  - **Final Score:** `floor + (relativePosition × scoreRange)`
  - Examples: minPct 20% → floor 54, minPct 40% → floor 56
- This creates 34-42 point spreads for meaningful differentiation

# 3. PROMPT ARCHITECTURE ASSESSMENT

## Overview
- **Total Levels**: 7
- **Format**: Free-text prompt writing
- **Evaluation**: GPT-5 powered scoring

## Scoring Criteria

| Criterion | Weight | Max Points | Description |
|-----------|--------|------------|-------------|
| Clarity | 20% | 20 | Is the prompt clear, unambiguous, and easy to understand? |
| Structure | 20% | 20 | Is the prompt well-organized with logical flow? |
| Context Relevance | 20% | 20 | Does the prompt provide necessary context and constraints? |
| Creativity | 20% | 20 | Does the prompt encourage thoughtful, creative responses? |
| Iterative Improvement | 20% | 20 | Does the prompt include mechanisms for refinement or building upon concepts? |

**Total**: 100 points per level (700 points maximum, averaged to 100)

---

## Prompt Levels

### Level 1: Basic Information Retrieval
**Description**: Create a simple, clear prompt for basic information

**Scenario**: You need to get a simple fact from an AI assistant.

**Task Instructions**: Write a prompt to ask for the capital city of France and 3 interesting facts about it.

---

### Level 2: Structured Output Request
**Description**: Request information in a specific format

**Scenario**: You need the AI to provide information in a structured way.

**Task Instructions**: Write a prompt asking the AI to list the top 5 programming languages for web development in 2024, formatted as a numbered list with a brief one-sentence description for each.

---

### Level 3: Role-Based Instruction
**Description**: Guide the AI to adopt a specific persona or expertise level

**Scenario**: You want the AI to explain a complex topic accessibly.

**Task Instructions**: Write a prompt asking the AI to explain quantum computing as if it were a senior physics professor teaching undergraduate students. The explanation should be accessible but accurate.

---

### Level 4: Multi-Step Problem Solving
**Description**: Design a prompt that guides through multiple steps

**Scenario**: You need the AI to solve a complex problem systematically.

**Task Instructions**: Write a prompt asking the AI to help debug a Python function that's supposed to find duplicates in a list but isn't working correctly. Include instructions for: (1) analyzing the code, (2) identifying the bug, (3) explaining why it's wrong, and (4) providing a corrected version.

---

### Level 5: Constrained Creative Generation
**Description**: Request creative content with specific constraints

**Scenario**: You need creative content that follows multiple specific requirements.

**Task Instructions**: Write a prompt asking the AI to generate a product description for a new eco-friendly water bottle. The description must: be exactly 100 words, include 3 key benefits, use language that makes people want to buy it, mention sustainability, and target health-conscious millennials.

---

### Level 6: Iterative Refinement Strategy
**Description**: Design a prompt that encourages self-improvement

**Scenario**: You need the AI to create and improve its own work.

**Task Instructions**: Write a prompt asking the AI to draft a professional email declining a job offer, then critically evaluate its own draft for tone, professionalism, and clarity, and finally provide an improved version based on that self-evaluation.

---

### Level 7: Complex System Design
**Description**: Guide the AI through complex multi-domain analysis

**Scenario**: You need comprehensive system architecture with multiple considerations.

**Task Instructions**: Write a prompt asking the AI to design a comprehensive content moderation system for a social media platform. The prompt should guide the AI to consider: technical architecture, ethical implications, scalability, false positive handling, appeals process, and provide a decision tree for different content types. Request a structured response with sections for each consideration.

# 4. AIQ (ALGORITHMIC INTEGRITY QUOTIENT) ASSESSMENT

## Overview
- **Total Questions**: 8
- **Options per Question**: 4 (A, B, C, D)
- **Format**: Weighted scoring (0-100 per answer)

## Scoring System
Unlike other assessments, AIQ uses **weighted option scores**:
- **Best Answer**: 100 points
- **Acceptable**: 65-75 points
- **Suboptimal**: 30-50 points
- **Poor**: 0-25 points

## Score Band Interpretations

| Band | Score Range | Title | Description |
|------|-------------|-------|-------------|
| Exemplary | 80-100% | Exemplary Ethical Alignment | Demonstrates exceptional understanding of AI ethics principles. Consistently prioritizes optimal ethical outcomes and shows sophisticated reasoning about complex trade-offs in algorithmic decision-making. |
| Strong | 60-79% | Strong Ethical Foundation | Shows sound ethical judgment with practical considerations. Understands core principles of responsible AI and can balance ethical imperatives with operational realities. |
| Developing | 40-59% | Developing Awareness | Basic ethical understanding with room for growth. Recognizes some ethical considerations but may prioritize convenience or efficiency over optimal ethical outcomes in certain scenarios. |
| Gaps | 20-39% | Significant Gaps | Needs substantial development in ethical reasoning. May underestimate the importance of consent, transparency, or bias mitigation in AI systems. |
| Critical | 0-19% | Critical Concerns | Fundamental misalignment with ethical AI principles. Responses suggest prioritization of outcomes over ethical process, requiring significant training and awareness development. |

---

## AIQ Questions

### Question 1
**Scenario**: A company builds an AI system to predict shopping trends using customer purchase data that was meant to be anonymous. Later, it is found that when this data is combined with public information, about 15% of customers can be identified. The AI works best when this combined data is used. What is the most ethical action?

| Option | Answer | Score |
|--------|--------|-------|
